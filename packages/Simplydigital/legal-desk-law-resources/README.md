# Legal Desk Law Resources

Reusable Laravel 13 and Livewire 4 package for Malaysian case-law research, judgment indexing, citation verification and saved AI research.

The package is under extraction from Legal Desk Assistance. The existing application's routes and data remain authoritative until integration is complete. Do not deploy this branch as a finished extraction.

## Installation (local path)

Add a Composer path repository pointing to `packages/Simplydigital/legal-desk-law-resources`, then require `simplydigital/legal-desk-law-resources:@dev`.

## Safety

AI-generated legal research is unverified. Check primary judgments and subsequent treatment. Only import judgments you are entitled to store.
