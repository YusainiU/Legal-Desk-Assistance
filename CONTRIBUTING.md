# Contributing

Discuss proposed changes with the maintainer before starting substantial work. Contributions are subject to the repository's licensing terms; public visibility alone does not grant permission to reuse the code.

Use a separate branch and follow existing Laravel, Livewire and Flux conventions. Include focused tests for changes to authorization, case workflows and deadline handling. Run Composer validation, dependency audits and the frontend build before submitting a pull request.

Use fictional data only. Never commit environment files, credentials, client records, database dumps or private attachments. Report vulnerabilities privately as described in SECURITY.md.

Describe the change, test results, migrations and any deployment implications in your pull request.
